# Kino Bot

**Kino Bot** ([@kontentallplay_bot](https://t.me/kontentallplay_bot)) is a Telegram bot that delivers movies to its users by code.

The bot also includes an admin-only tool: the bot owner sends a short video and a description to the bot, and the bot publishes it as a **YouTube Short** to the owner's own YouTube channel using the YouTube Data API. Only the channel owner authorizes this access, and the bot only uploads videos that the owner explicitly sends.
