# Privacy Policy

_Last updated: October 4, 2026_

This Privacy Policy describes how **Kino Bot** (Telegram bot [@kontentallplay_bot](https://t.me/kontentallplay_bot), "the bot", "we") collects, uses and protects information.

## 1. Telegram users

When you use the bot in Telegram we store only what is needed for the bot to work:

- your Telegram user ID, name and username (provided by Telegram);
- the date you started the bot and your last activity date;
- the movie codes you requested, ratings you gave and movie requests you sent;
- payment records (amount, date, status) and payment screenshots you send to confirm a payment.

This data is used only to operate the bot (deliver movies, Premium subscriptions, statistics for the bot owner). It is not sold or shared with third parties.

## 2. YouTube API Services

The bot uses **YouTube API Services** for one purpose only: to let the bot owner (administrator) upload short videos to **their own** YouTube channel.

- **By using this feature you agree to be bound by the [YouTube Terms of Service](https://www.youtube.com/t/terms).**
- Google's use of data is governed by the **[Google Privacy Policy](https://policies.google.com/privacy)**.
- **Data accessed:** with the owner's consent (OAuth scope `youtube.upload`) the bot receives an access token that allows it to upload videos and set their title, description and thumbnail. The bot does not read, collect or store any other YouTube or Google account data, and it does not access the YouTube data of Telegram users.
- **Storage:** the OAuth refresh token is stored only in the bot's own database on the owner's server. The uploaded video file is kept temporarily only while it is being uploaded and is deleted afterwards. We store the ID of each uploaded video so the owner can see the upload history.
- **Sharing:** YouTube/Google data is never shared with or sold to anyone.
- **Revoking access:** the owner can revoke the bot's access at any time in the bot's admin panel or on the Google security settings page: [https://myaccount.google.com/permissions](https://myaccount.google.com/permissions). After revocation the stored token is deleted.

## 3. Data retention and deletion

Telegram users can ask for their data to be deleted by writing to the contact below. Stored YouTube tokens are deleted as soon as access is revoked or the feature is disabled.
